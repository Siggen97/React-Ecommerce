# Ecommerce site

![Ludvigs Shop] (https://www.imghippo.com/files/c937I1728815866.png)


## Description
An Ecommerse site buildt with
Homepage
Individual product page
Cart page
Checkout success page

The Homepage havs a list of all the products. 
There is a look-ahead search bar that filters products when typing in a product name. 
Clicking on a product takes a user to an individual product page.
Individual product page displays data for a single product. There is an Add to cart button which, upon clicking, adds the product to the cart. 
The product page displays the title of the product, the description and the image. There is also reviews listed for the product, if there are any. There is discountedPrice property to display the price of the product. If there is a difference between the discountedPrice and price properties then that means there is a discount for that product. It calculates what this discount is and display it on the page.

Clicking on the Cart icon will load the Cart page, which will list all of the products as well as a total. 
The Cart page will have a Checkout button. Clicking this Checkout button then goes to a Checkout success page.

The Checkout success page will display a message to the user notifying them that their order was successful. 
There is also a link that lets a user go back to the store. The cart is then cleared if the user gets to the Checkout success page.

There is a contact page which will contain a contact form.

## Getting Started

### Installing

1. Clone the repo:

```bash
git clone https://github.com/Siggen97/Semester-Project-2.git
```

2. Install the dependencies:

```
npm install
```

### Running

To run the app, run the following commands:

```bash
npm run start
```
